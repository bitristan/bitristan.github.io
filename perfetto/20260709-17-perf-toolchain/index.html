Perfetto （十七）：性能分析工具链

工具链的三层架构

Section titled “工具链的三层架构”

Perfetto 的性能分析工具链由三层组成：Metrics 框架（结构化指标输出）、Wattson（功耗估算）、可视化模块（火焰图和时间线）。它们都构建在 PerfettoSQL 之上，但服务于不同的分析场景。

Metrics 框架

Section titled “Metrics 框架”

设计哲学

Section titled “设计哲学”

Metrics 是 Perfetto 的结构化分析输出。每个 metric 是一个 SQL 文件，执行后产生嵌套的 protobuf 消息。这使得 CI 系统可以程序化地解析和比较 metric 结果——不仅仅是文本报告。

核心机制

Section titled “核心机制”

SqlMetricFile（metrics/metrics.h）定义了每个 metric：

ComputeMetrics() 的执行流程：

  1. 执行 metric 的 SQL 文件（可能通过 RUN_METRIC('path') 引用其他文件）。
  2. SQL 查询结果通过 build_proto(...) 函数构建 protobuf 消息。
  3. ProtoBuilder 将列值映射到 protobuf 字段，检查 schema 一致性。
  4. RepeatedFieldBuilder 处理 repeated 字段的聚合。

build_proto 函数

Section titled “build_proto 函数”

build_proto 是一个注册的 C++ 标量函数，将列名-值对组装为嵌套的 protobuf 消息。

Wattson：功耗估算系统

Section titled “Wattson：功耗估算系统”

设计目标

Section titled “设计目标”

Wattson 是 Perfetto 的软件功耗估算框架。它不依赖硬件功耗计——而是基于 CPU 频率、idle 状态和设备功耗曲线来估算每个线程/进程的能耗。

四层架构

Layer 2：频率/idle 状态追踪

Section titled “Layer 2：频率/idle 状态追踪”

wattson/cpu/freq_idle.sql 构建 _idle_freq_materialized——将 CPU 频率计数器、idle 状态和 CPU hotplug 状态交叉关联，为每个时间区间分配 (频率, idle, 在线/离线) 三元组。

离线 CPU 的功率为零。使用 counter_leading_intervals! 宏将计数器值转换为区间。

任务归因

Section titled “任务归因”

wattson/tasks/attribution.sql 将功耗归因到线程：

  1. _estimates_w_tasks_attribution——将系统状态与每个 CPU 上运行的任务交叉关联。

可视化模块

Section titled “可视化模块”

火焰图

Section titled “火焰图”

viz/flamegraph.sql 实现了完整的火焰图生成管道：

1. 过滤：_viz_flamegraph_prepare_filter 应用 show/hide/pivot 过滤器。

2. 森林遍历：_viz_flamegraph_filter_frames 从根到叶遍历调用树，移除被过滤的 frame，将 pivot 节点设为新根。

3. 累积：_viz_flamegraph_accumulate 通过 _graph_scan! 自底向上累积值。

4. 哈希：_viz_flamegraph_upwards_hash / _viz_flamegraph_downwards_hash 为每个节点计算上下方向的哈希值，用于去重。

5. 布局：_viz_flamegraph_local_layout / _viz_flamegraph_global_layout 计算节点的渲染位置。

火焰图支持 pprof 格式输出——experimental_profile() 生成兼容 Google pprof 工具的 profile 数据。

时间线数据

Section titled “时间线数据”

viz/slices.sql 和 viz/threads.sql 为 Perfetto UI 的时间线视图提供数据：

  • Slice 的分组、嵌套、深度计算
  • Thread 的可见性、排序、分组

Trace 摘要

Section titled “Trace 摘要”

viz/summary/ 目录生成 trace 的结构化摘要：

  • trace_summary.sql：trace 的基本信息（时长、CPU 数、进程数）
  • processes_summary.sql：进程级摘要
  • slices_summary.sql：slice 统计
  • threads_summary.sql：线程统计
  • counters_summary.sql：计数器统计

本文小结

Section titled “本文小结”

Perfetto 的性能分析工具链由 Metrics 框架、Wattson 功耗估算和可视化模块组成。Metrics 将 SQL 查询结果组装为结构化 protobuf 输出，支持 CI 集成和跨版本比较。Wattson 通过四层架构（功耗曲线→频率追踪→CPU 估算→系统聚合）实现无需硬件计的功耗估算，并支持按线程归因。可视化模块的火焰图管道实现了从过滤到布局的完整流程。这些工具都构建在 PerfettoSQL 之上，通过模块化设计支持自由组合。
